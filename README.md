# Keiko-ryõ

Sistema de controle de aulas e pagamentos para artes marciais

## Funcionalidades
- Cadastro de alunos, aulas e pagamentos
- Edição de alunos, aulas e pagamentos
- Exclusão de alunos, aulas e pagamentos

## Requisitos
- Python 3.14.7
